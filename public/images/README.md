# Images

Drop content images here. Paths referenced from the JSON data files resolve
against this folder (Vite serves `public/` at the site root).

Expected assets (referenced by the starter JSON):

- `about/portrait.jpg` — your portrait for the About section
- `skills/*.svg` — technology icons (csharp, python, docker, linux, typescript, react …)
- `experience/*.svg` — company logos referenced by `src/data/experience.json`
- `projects/*.png` — project screenshots referenced by `src/data/projects.json`

You can change any of these paths by editing the corresponding file in
`src/data/`.
