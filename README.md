# Saad Wasim — Personal Website

A modern, modular personal portfolio website built to showcase my experience, projects, technical skills, and professional background as a Software Engineer.

The website uses a **JSON-driven content architecture**, allowing content to be updated without modifying React components. Most personal information can be changed by editing the files in `src/data/`.

## Features

- Responsive personal portfolio
- JSON-driven content management
- Modular React component architecture
- Work experience timeline
- Project showcase
- Technical skills section
- Contact information
- Social media links
- Client-side routing
- Framer Motion animations
- Black and Gold visual theme
- Reusable shadcn/ui components

## Tech Stack

### Frontend

- React 18
- TypeScript
- React Router
- Tailwind CSS
- Framer Motion
- Vite

### UI

- shadcn/ui
- Tailwind CSS
- Custom Black and Gold theme
